# health-llm-variability

Official repository for the paper "[Challenges of Auditing: Variability in Outputs of Large Language Models for Health](https://arxiv.org/abs/2609.16590)".

## About

People increasingly use frontier AI models for health advice, but via different access modes (e.g., ChatGPT, ChatGPT Health, APIs) with varying settings. Using the same set of consumer health questions, we collected responses from ChatGPT, ChatGPT Health, and the OpenAI API, and find systematic differences across access modes.

This repository contains the sampled health questions, the collected responses from each access mode, and the code and prompts used to extract response features and produce the reported results.
